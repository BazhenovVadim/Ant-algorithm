# Алгоритм муравьиной колонии (Ant System), Java

Лабораторная работа: решение задачи коммивояжёра муравьиным алгоритмом с визуализацией на Swing.

## Структура

- `src/aco/Node.java` — узел сети (город)
- `src/aco/Edge.java` — путь между городами (длина, феромон)
- `src/aco/Graph.java` — среда: полный граф
- `src/aco/Ant.java` — муравей: выбор пути по P = τ^α·η^β / Σ(τ^α·η^β), перемещение
- `src/aco/Colony.java` — колония: испарение τ·(1−ρ), откладывание Δτ = Q/L
- `src/aco/GraphPanel.java` — визуализация (толщина ребра = феромон, красный пунктир = лучший маршрут)
- `src/aco/Main.java` — запуск (GUI и консольный режим с проверкой полным перебором)
- `docs/uml/*.puml` — UML-диаграммы для отчёта (PlantUML)

## Сборка и запуск

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/aco/*.java

java -cp out aco.Main                  # окно с визуализацией
java -cp out aco.Main --headless 1000  # консоль: 1000 циклов + сверка с оптимумом
```

## Параметры по умолчанию

α = 1 (феромон), β = 3 (расстояние), ρ = 0.5 (испарение), Q = 1000, 10 узлов, 10 муравьёв.
Начальная популяция: муравьи равномерно распределены по узлам, феромон на всех рёбрах одинаковый,
поэтому в первых циклах муравьи ходят по дорогам случайно. Через несколько сотен циклов все муравьи
идут по кратчайшему маршруту.

## Диаграммы

Файлы `docs/uml/*.puml` можно открыть на https://www.plantuml.com/plantuml или в IDE с плагином PlantUML
и экспортировать в PNG для отчёта.
